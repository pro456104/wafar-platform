# Project-Technologies.txt — mirror

**Status**: mirror, not a source. The register of the approved technology stack is
`.specify/memory/constitution.md` → **Technology Standards**. Where this file and
that section disagree, the constitution wins.

Read in the register: the repository topology, the internal layout, the approved
stack with its version floor and notes, the MAJOR/MINOR version-change rule, the
gaps a slice MUST close (with the owning slice for each), and the licence
treatment for infrastructure services.

This file exists only so that a reader arriving from an older reference finds the
register immediately. It MUST NOT be extended with technology detail: a second
copy of the register is a drift defect (constitution → Single-Reference
Sufficiency). ADR-008 records the decision.

**History**: the detailed version of this file — with per-technology notes,
versions, and the repository trees — was recorded in the baseline commit before
the constitution v2.7.0 amendment, and is still recoverable:

    git show 78ba68c:Project-Technologies.txt
